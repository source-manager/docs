    What ● means for the AI row here

    Bring-your-own-key and local models — no credits, no account, nothing resold — with hosted models off until switched on globally and per repository. It is also, like the two forges, fixture-proved and not live-proved: the suite cannot reach a model, so it pins the shape and cannot say a real one answers well.

    Feature inventory, by category¶

    The union of what the field offers. ✔ present here, ✗ absent, ~ partial.

    Repository and fleet management¶

    Feature Here Notes on the field
    Add / clone / open repository ✔ universal
    git init a new repository ✔ universal
    Create the repository on the forge too, wire origin ✔ GitKraken, GitHub Desktop; rare
    Scan a folder for repositories ✔ Fork, SmartGit, SourceGit
    Group / tag / order repositories ✔ GitKraken Workspaces 💰, SmartGit, SourceGit
    Multi-repo dashboard (drift, dirt, stopped ops) ✔ GitKraken 💰; rare and strong here

    Recently-used repository switcher ✔ universal
    Repository tabs / multiple windows ✔ a second window Fork, Sublime Merge, Sourcetree, Tower
    Shell / Explorer integration with status overlays ✗ declined TortoiseGit (its whole point)

    Remotes and transport¶

    Feature Here Notes
    Add / rename / set-url / remove remote ✔ universal
    Fetch with prune, progress, cancel ✔ universal
    Push, push with lease, plain force behind a dialog ✔ the three-verb split is more careful than most
    Pull with ff-only / merge / rebase ✔ universal
    Clone with progress and cancel-cleanup ✔ universal
    Credentials: ssh-agent, explicit key, token ✔ universal
    Fetch, or fetch and prune, as a one-off choice ✔ most make prune a setting only
